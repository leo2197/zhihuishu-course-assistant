# 智慧树 AI 智课助手（Windows 测试版）

自动打开专用Edge，按平台进度处理未完成的视频、可重练掌握度及可选课程讨论。面向Windows x64；当前课型为智慧树AI智课，已验证范围有限，普通智慧课程和其他平台不能据此视为兼容。

**普通用户：[下载 Windows 运行包](https://github.com/leo2197/zhihuishu-course-assistant/releases/download/v0.1.0-alpha.2/Windows-x64.zip)** · [版本说明](https://github.com/leo2197/zhihuishu-course-assistant/releases/tag/v0.1.0-alpha.2) · [常见问题](FAQ.md)

下载后先看包内“先看这里.txt”。不要下载GitHub自动生成的Source code包来代替Windows运行包；运行包自带Node，无需自行安装开发环境，需要已有Microsoft Edge。

## 下载后第一次使用

1. 从Releases下载命名的Windows运行包，完整解压到可写文件夹，双击「启动.cmd」。不要在ZIP内直接运行。
2. 按首次设置提示填写学校、学号和姓名；姓名和学号会在实际课程页再次核对。选择是否启用自动发表课程讨论。
3. 填写兼容Chat Completions的API服务地址、自己的API Key、主答与裁决模型ID。Key输入不回显，保存时使用Windows当前用户加密。检测可能产生少量模型调用费用；检测失败不会覆盖原来可用的设置。
4. 脚本自动打开专用Edge。第一次请本人选择学校、输入密码并完成验证码/滑块/短信等安全验证。
5. 在“我的学堂”点击要学习的AI智课，进入学习目录后自动记录选择；也可在脚本窗口粘贴AI智课学习页完整网址。
6. 核对实际姓名和学号通过后开始任务。学校、学号与密码只在首次登录成功且身份匹配后加密保存，不上传给模型。

## 以后如何启动

直接双击「启动.cmd」。优先使用已有登录状态；失效时尝试自动填写保存的学校、学号和密码并登录一次。平台安全验证由本人完成，脚本发出明确提示并保留任务；验证消失后再核对状态继续。密码变更、凭据失效或换Windows账号时，可能需要重新输入，不能保证永远只需验证码。

凭据依赖当前Windows用户与电脑，不能直接把密文复制到朋友电脑使用。浏览器与脚本均可见；可最小化浏览器，不要求安装扩展、关闭安全软件或手动开启远程调试。默认使用专用浏览器资料，不导入个人普通浏览器账号。

## 模型怎样配置

双击「设置.cmd」→「模型设置与检测」。

- API地址：服务商给出的API基础地址（如`https://服务商域名/v1`）或完整`/chat/completions`地址，不是普通聊天网页地址。
- API Key：从你自己的服务商控制台复制；不能填充值卡密，不内置维护者密钥。
- 模型ID：复制该服务实际支持且当前Key有权限的模型ID。主答和裁决可分别指定；图片裁决需支持图片输入。
- 设置会分别检测主答、裁决权限。无效Key、模型不存在、余额不足、限流和超时会给出具体下一步。

检测通过只表示接口与权限可用，不保证题目全部答对或每个服务都支持全部高级参数。API费用和免费额度以你自己的服务商为准。

## 如何选择课程、切换账号和增加窗口

- 换课：双击「选择课程.cmd」，在专用浏览器打开目标AI智课目录，核对身份后保存；下次启动使用所选课程。运行中的任务先结束，再切换。
- 换账号：双击「切换账号.cmd」，从已记住账号中按序号选择，或添加学校/学号/姓名。不同账号使用独立浏览器资料、密码密文和提交记录；首次仍需本人登录。
- 并发：双击「设置.cmd」→「并发窗口数量」，可设1到4，建议从2开始。窗口共享待办队列，先做完的领取下一项，同一点位有锁，不会故意重复处理。只剩一个可处理知识点时不能把同一试卷拆给多个窗口交卷。
- 限流或卡顿：先降低窗口数，再检测服务。更多窗口不保证更快，特别是只剩一个任务、遇到验证或模型服务限流时。

## 按课程成绩要求选择任务

每次启动先读取该账号、该课程“成绩分析”的各项占比，保存任务判断依据。仅为占比明确大于0的项目安排任务；零占比或平台明确免考跳过。占比未知不猜测执行，保留提示。评论只有计分、未完成且用户开启自动发表时才运行；考试和线下成绩会列为需本人/平台安排的项目。

视频和掌握度的免考分别判断：只免掌握度不会跳过仍需观看的视频，只免视频仍处理计分掌握度；“申请免考”不等于已免考。视频资源自身的免考标记也会跳过。最终核验只统计计分且未免考的要求，未知要求不冒充完成。

流程出现暂时异常或一批练习结束仍有在线任务，会等待60秒后重新核对，不以一批结束当课程完成。交卷跳转超时保留原记录：平台明确已交卷则核对成绩和逐题解析；明确确认原卷未交且原作答逐题一致，才恢复该卷一次。正式考试、状态不明或作答不一致均不自动重交。浏览器关闭表示结束本次程序。

## 状态与进度

进度行只显示正在进行部分的已完成数量/总数量，例如`进度｜掌握度 12/46`。已完成的评论、未开始的部分、总体合计和百分比不显示，其他题目日志与提示保留。

首次登录、自动登录、记忆成功、等待本人验证、登录失败、身份不符、未确认提交会分别提醒。查看日志不等于任务完成；单卷全对也不等于知识点100掌握度。免考项按平台明确状态跳过。

可重练练习的不确定答案处理由账号设置控制；首次默认等待本人核对。有限次数或正式考试不会当作可重练知识点提交。提交反馈不明确时保留保护记录，不能通过删除data或重新安装来强行重交。

## 数据、升级与已知限制

运行后会生成`data/`、`profiles/`、`config/`和`logs/`。不要把这些文件夹上传到公开仓库或发给别人，里面包含个人学习记录、登录资料或模型设置。换版本前退出程序并备份自己的这些目录；不要覆盖或删除提交保护。

每账号、每课程的学习缓存独立保存。公开包不附带个人答案库；只学习当前使用者已核对的平台解析。讨论发布前后核对本人回复，状态不明不重复发送。

目前没有承诺支持Mac、所有智慧树课型或所有模型服务。线下到课、未发布考试/论文、未来签到等要求不能据此认定完成。浏览器最小化与特殊编辑器、页面改版仍需持续实测，遇到异常保留日志并反馈。

## 从源码运行

需要Node.js 22及以上和Microsoft Edge。首次执行`npm ci`，再运行「启动.cmd」完成设置。`npm test`使用本地模拟页面与假账号，不需要真实API Key；Windows凭据测试需在Windows运行。

运行`node build-public.cjs`生成源码候选包与Windows便携运行包。构建采用白名单，排除实际账号配置、Key、密码密文、浏览器资料、日志、个人题库和调试工作目录。发布前必须在干净Windows环境验收，测试通过不能替代真实课程适配验证。
