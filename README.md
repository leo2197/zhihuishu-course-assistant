# 智慧树课程助手（Windows 测试版）

[下载 Windows 运行包](https://github.com/leo2197/zhihuishu-course-assistant/releases/download/v0.1.0-alpha.7/Windows-x64.zip) · [版本说明](https://github.com/leo2197/zhihuishu-course-assistant/releases/tag/v0.1.0-alpha.7) · [常见问题](FAQ.md)

根据成绩分析处理未完成的计分视频、掌握度和可选讨论。适用Windows 10/11 x64与当前已适配的智慧课程新形态学习页，不代表全部智慧树课程均兼容。

## 第一次使用：先配API，再网页登录

1. 下载 **Windows-x64.zip**，右键“全部解压”，保留完整app文件夹，双击唯一的“启动.cmd”。首次直接进入引导，不用先选菜单。不要在ZIP预览中运行，也不要只拖出CMD。
2. **只填API地址和API Key。** 推荐GLM：API地址已预填，直接回车即可。Key隐藏输入，粘贴后按回车。其他服务商填写自己的兼容接口地址和Key。
3. 自动读取模型列表并检测主答与裁决，显示选中的模型；不用记模型ID。检测通过后自动打开智慧树网页。
4. **在网页选择学校、登录并完成安全验证。** 控制台不填写学校、学号或姓名。
5. 登录后回到脚本窗口，程序只读取首页“智慧课程”区域，列出课程名、老师和页面学习进度。**输入课程序号**，脚本自动进入该课程的“知识学习”，读取本人账号与成绩分析后开始。输入R刷新列表；网页选课和粘贴知识学习页完整网址保留作备用。

Windows运行包自带Node和依赖，需要已有Microsoft Edge。GitHub自动生成的Source code面向开发者，需要自行安装依赖，不是Windows运行包。检测和学习会产生模型调用费用，以自己的服务商计费为准，不承诺免费或满分。

## 推荐GLM，也允许自由配置

- 默认API地址：`https://open.bigmodel.cn/api/paas/v4`。GLM的Key管理网页是`https://open.bigmodel.cn/apikey/platform`，不是API地址；本工具会识别这一误填并使用官方接口。
- GLM优先检测主答、裁决与可确认的图像模型，实际选择会显示出来，权限不够会明确提示。检测失败不覆盖原来的可用设置。临时连接失败会自动重试一次；仍失败可输入R，用本次地址和Key重新检测，不必重新粘贴Key。GLM模型列表不可用时，继续用实际调用检测官方已知模型。
- 其他兼容服务：填写其Chat Completions接口与自己的Key，优先自动读取模型列表。服务未开放列表时，会提示进入高级设置，不强制更换服务商。
- 自选模型：启动菜单→2“模型设置”→输入2“高级”，自行填写主答、裁决与可选图像模型ID。默认自动模式只问地址和Key。
- 图像能力未确认时，图片题交本人核对，不把文字模型当图像模型。

官方依据：[智谱接口兼容说明](https://docs.bigmodel.cn/cn/guide/develop/openai/introduction)、[GLM-5.3-Flash说明](https://docs.bigmodel.cn/cn/guide/models/vlm/glm-5.3-flash)。模型与权限可能调整，以实际检测为准。

## 以后只用一个启动入口

再次双击“启动.cmd”，菜单可开始/继续、设置模型、换课、换账号、调整并发或阅读说明。

换课：菜单选3，自动读取课程列表后输入新课程编号即可。换账号：菜单选4，已有账号按序号选择；新增账号直接去网页登录，不在终端填写个人信息。各账号的浏览器资料和提交记录独立保存。

优先复用登录状态；失效时尝试填写已记住的信息。只有首次学号密码登录被捕获且网页身份匹配后，凭据才用Windows当前用户加密保存在本机；扫码登录、密码修改或凭据失效时可能需要本人重新登录。滑块、短信等安全验证始终由本人完成，脚本提示并等待，验证后自动核对继续。

默认不列出首页前面的“AI智课”卡片。智慧课程页面的学习进度100%不等于掌握度、讨论或其他计分要求已完成，因此仍可选入，进入后再按成绩分析决定具体任务。入口不是已支持知识学习页的课型暂不自动处理。

## 任务如何筛选、异常如何处理

每次先读成绩分析占比。0权重、已完成和明确免考跳过，视频与掌握度分别判断免考；申请免考不等于已免考。未知要求保留提示。自动评论默认关闭，未开启的计分讨论需本人处理。考试、线下等要求会列出，在线任务完成不能算整课满分。

进度只显示正在处理部分的已完成/总数量，其他日志保留。任务页共享待办队列，不重复处理同一知识点；只剩同一份测验时增加窗口不会更快。

临时异常或一批练习结束仍有在线任务，会等待60秒重新核对。交卷反馈不明保留原记录：明确已交只核对结果；平台明确未交且原作答逐题一致时，才恢复原卷一次。状态不明、作答不一致、正式考试不强行重交。裁决不确定时，默认等本人输入答案并确认。

## 数据与限制

修改账号、课程或模型前，等待当前试卷反馈结束，再关闭专用Edge结束任务。升级先备份并保留data/profiles/config与配置文件、提交记录，新旧版本不要同时运行。不要删除data规避提交保护。

公开包不含个人账号、Key、Cookie或题库。运行后生成的data/profiles/config/logs都是私人资料，不能上传或发给朋友；朋友使用公开下载包自行配置。密文依赖当前Windows用户，不能保证跨电脑使用。

测试版不支持Mac或全部智慧树课型，不能保证题题满分，也不能保证所有特殊页面都不抢前台。隔离测试不等于所有电脑与服务商实测。考试、线下、论文及未来签到等要求需按平台安排处理。

## 开发

需要Node.js 22+和Edge。运行`npm ci`、`npm test`；测试用假账号和假接口，不需真实Key。`node build-public.cjs`按白名单生成源码与Windows包。不要整体提交个人运行目录。
