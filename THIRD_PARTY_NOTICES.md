# Third-party components

The MIT license at this project root covers the original assistant modules.
Legacy OCS user scripts are not included in the public build whitelist.

- Playwright and Playwright Core: Apache-2.0. Their license and notice files remain inside the distributed node_modules packages.
- Node.js: the Windows portable runtime is downloaded from nodejs.org and verified against the matching SHA-256 published there. The corresponding upstream LICENSE is included beside node.exe.
- Microsoft Edge is not redistributed; users use an installed copy. Browser and course-platform services retain their own terms.
