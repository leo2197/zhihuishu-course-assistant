智慧树 AI 智课助手 · Windows 测试版

你需要准备：64位 Windows 10/11、Microsoft Edge、自己的学校账号，
以及兼容 Chat Completions 的模型服务地址、API Key 和模型ID。
不附赠模型额度。暂不支持Mac和全部智慧树课型，不保证测验满分。

一、下载并完整解压
在GitHub Releases下载 Windows-x64.zip，右键“全部解压”。
保留整个文件夹：启动文件旁边的app文件夹不能删除或移动。
不要在ZIP里双击，不要只把“启动.cmd”单独拖到桌面。

二、双击“启动.cmd”
控制台依次显示4步：检查环境 → 账号与模型设置 → 组件检查 → 打开浏览器。
第一次按提示输入学校全称、数字学号、姓名，用来防止操作错账号。
自动讨论默认关闭；开启后也只处理计分且未完成的讨论。

三、设置自己的模型
API地址：从服务商复制API基础地址或/chat/completions地址，不是聊天网页。
API Key：复制API密钥，不是充值卡密。粘贴后不显示字符属正常，按回车继续。
主答模型ID：填服务商实际支持且你的Key有权限使用的ID。
裁决模型ID：可填更强的模型；只用一个模型时按回车沿用主答。
图片裁决模型：需要支持图像输入；普通文字模型不能保证处理图片题。
检测会产生少量模型调用；失败按屏幕原因修正，不会覆盖原来的可用设置。

四、本人首次登录并选课
专用Edge会自动打开。首次请本人选择学校，输入账号密码并完成安全验证。
在“我的学堂”打开要学习的AI智课，进入知识学习目录后脚本自动记住课程。
也可以把该学习目录完整网址粘贴到脚本窗口，按回车。
姓名和学号核对通过后才开始任务，并加密保存登录信息。
下次优先复用登录状态；失效时尝试自动填写，滑块/短信等验证仍需本人完成。
密码修改或本机凭据失效时可能需要重新输入。

运行时你会看到什么
- 先列出成绩分析中的占比与任务判断；零占比、已完成和明确免考项跳过。
- 视频和掌握度分别判断免考，申请免考不会当成已免考。
- 进度只显示正在处理部分的计数；模型核验和其他提示继续保留。
- 等待安全验证时，从任务栏打开专用Edge完成验证，不需要重开脚本。
- 裁决不确定时，默认等待你在控制台输入答案字母，并输入“确认”。
- 暂时异常等待60秒后重新核对；交卷不明保留保护，不能删除记录强行重交。
- 自动任务完成后，如仍有考试、线下等要求会明确列出，不冒充整课完成。

四个入口怎样用
启动.cmd：继续上次账号和课程。
设置.cmd：修改模型、账号、选课及并发数量；建议先用2个知识点任务页。
选择课程.cmd：登录后打开另一门支持的AI智课，保存新选择。
切换账号.cmd：选择已有账号或新增，浏览器资料和提交记录按账号隔离。
修改前等待当前试卷反馈完成，再关闭专用Edge结束任务，避免在途切换。
同一份测验不会交给多个窗口重复处理，更多窗口不一定更快。

退出与升级
暂时离开可以最小化浏览器，保留脚本窗口。结束本次任务可关闭专用Edge。
不要同时启动多个程序副本。程序没有承诺所有页面都不会抢前台。
升级前退出并备份旧版app中的data、profiles、config、settings.json和
model-config.json，迁移时保留提交记录；不要让旧、新版本同时运行。
